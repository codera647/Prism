Prism 0.5.0 changes the interface to green and gray, adds a campaign dashboard and Agent Reach upstream web search, and provides editable Gemini image prompts. Existing boards, CLIP, patterns, experiments, Gemini, chat and exports remain available. Desktop accounts and image boards remain local; device-mode Gemini keys remain in memory.

The hosted app includes a Google-account backend, encrypted persistent provider keys, saved campaigns/ideas and optional Muapi product designs. Activation requires Cloudflare D1 access and Google OAuth credentials, which were unavailable during this work. Muapi generation needs provider credits; no paid generation is claimed. The adapter is independently implemented from Open-Higgsfield's observed protocol, with no upstream code vendored.

Verification: 45 Python contracts and 36 browser/source/DOM/account tests passed locally. Provider responses and Google sessions in account tests are fixtures. GitHub Actions verifies real packaged CLIP before publication. Live Google login, provider image generation and browser/native visual inspection remain open checks.
