# Prism bundled components

Prism uses Trailforge, FastAPI, Uvicorn, Pillow, NumPy, scikit-learn, OpenCLIP, PyTorch,
torchvision, timm, safetensors, pywebview, Python.NET, WebView2 and PyInstaller.
Their package license/notice files are included by the desktop build where supplied.
WebView2 is supplied by Microsoft and is required on the target Windows computer.

OpenAI CLIP source and pretrained model: https://github.com/openai/CLIP
OpenCLIP implementation: https://github.com/mlfoundations/open_clip
Trailforge source: https://github.com/codera647/Trailforge/tree/v0.1.0a1

The model is distributed as hash-verified tensor-only weights. It is not trained
by Prism. Downloaded real-image evaluation photos are not bundled in this application.
